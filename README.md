# diplom-project
Дипломный проект - "Проектирование структурированной кабельной сети для офиса интернет-магазина, с сегментированием сети"


**Специальность:** 09.02.06 Сетевое и системное администрирование  
**Место защиты:** ГБПОУ «ППК им. Н.Г. Славянова», 2026 год

## Описание

Проект включает разработку сетевой инфраструктуры офиса интернет-магазина:
- Проектирование физической и логической топологии сети
- Сегментирование сети через VLAN
- Настройка маршрутизации между сегментами
- Реализация топологии в Cisco Packet Tracer

## Файлы

- `network.pkt` — топология сети в Cisco Packet Tracer 6.2
- [Сайт защиты проекта](https://andreevn1.github.io/site_final/index.html)

## Стек

- Cisco Packet Tracer 6.2
- Протоколы: VLAN, STP, DHCP, DNS, NTP, SYSLOG, HTTP, FTP, GRE, OSPF.
